🚀 QUICK START:

  1. Setup Environment:
     python -m venv venv
     source venv/bin/activate

  2. Install:
     pip install -e .

  3. Configure:
     cp .env.example .env
     # Add your ANTHROPIC_API_KEY to .env

  4. Run:
     python -m src.cli.main

  5. Try Commands:
     > summary
     > Add monthly income of $3000 from salary
     > Add monthly expense of $1200 for rent
     > What's my balance?
