## 5-Minute Setup

```bash
# 1. Setup environment
python -m venv venv
source venv/bin/activate

# 2. Install
pip install -e .

# 3. Configure
cp .env.example .env
# Add your ANTHROPIC_API_KEY to .env

# 4. Run
python -m src.cli.main

# 5. Try it!
> summary
> Add monthly expense of $1200 for rent
> What's my balance?
```
